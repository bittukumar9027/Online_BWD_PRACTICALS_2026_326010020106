Subject Details

1.Basics of Web Development

This subject introduces HTML. CSS, web pages, hyperlinks, and the basics of website development.

2.Programming Practices - 1(Basic of C)

This subject covers basic C programming, variables, data types, operators and conditional statements.

3.Architectural Organization of Computer

This Subject explains computer components, memory, processors, and computer Organization.

4.Mathematics - 1

This subject covers basic Mathematics concepts used in computer applications.

5.Enterpreneurship

This subject introduces business ideas, enterpreneurship,and business planning.

6.Environmental Science

This subject explains the environment, natural resources, pollution and conservation.

7.Web Development Lab

This practical subject provides hands-on experience in creating web pages using HTML and CSS.

8.C Programming Lab

This practical subject develop programming skills through basic C language programs.
